## 2. Эрх (нэвтрэлтгүй үе шат)

Хэрэглэгч баруун дээд булангаас «Би хэн бэ» (нэр + үүрэг)-ээ сонгоно → хүсэлт бүр `X-AR-Role`, `X-AR-Name` толгойтой → эрхийг backend шалгана. Нууц үггүй тул баталгаажуулалт биш; SSO холбоход зөвхөн энэ давхарга солигдоно. Нэвтрэлтийг асаавал (`node server/users.js login on`) нэрийн хэрэглэгч + нууц үг.

| Үйлдэл | Захирал | Менежер / хянагч | Аудитор | Харах |
|---|---|---|---|---|
| Тайлан оруулах, хяналт эхлүүлэх | ✓ | ✓ | ✓ (өөрийн) | — |
| Бүх санал харах | ✓ | ✓ | зөвхөн зөвшөөрсөн | ✓ |
| Санал шийдвэрлэх (S5) | ✓ | ✓ | — | — |
| Эцэслэн батлах (S10) | ✓ | — | — | — |
| Лог харах | ✓ | ✓ | — | — |

Бэлтгэгч ≠ шийдвэр гаргагч: нэрээ сонгосон үед өөрийн оруулсан тайлангийн саналыг шийдвэрлэх боломжгүй (409).

## 3. Эцсийн батлалт (S10)

Анхны review-ийн хуудсан дээр «✔ Эцэслэн батлах» (зөвхөн захирал). Нөхцөл: сүүлийн давталтын verdict READY эсвэл READY_WITH_FIXES. Үр дүн: бүртгэлийн дугаар `RPT-174-YYYY-NNN`, батлагдсан огноо, `archive/<дугаар>/` (Word, Excel, approval.json — 10 жил, 7 хоногийн устгалд хамаарахгүй), audit лог; цаашид шийдвэр өөрчлөх, засвар оруулах түгжигдэнэ.
