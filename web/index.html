Тайлангаа хянуулах

Аудитын тайлан, Excel хавсралтаа оруулж дээд шатны хянагчийн байр сууринаас үнэлгээ авна.

Нэвтрэх нэр = имэйлийн @-ийн өмнөх хэсэг (бүтэн имэйлээр ч болно). Нууц үгээ мартсан бол admin-д хандана.
Анхны тохиргоо: серверийн цонхонд харагдах кодоор орж өөрийгөө admin болгон бүртгэнэ. Дараа нь хэрэглэгч бүр өөрийн нэр, нууц үгээр нэвтэрнэ.
Түр нууц үгээ өөрийн нууц үгээр солино уу.
Хувийн мэдээлэл Claude-д илгээхээс өмнө далдлагдана
Файлууд шифрлэгдэж, review дуусмагц устна
Эцсийн шийдвэрийг хянагч гаргана — агент зөвхөн туслана

1Аудитын мэдээлэл

Файлаа хайрцаг руу чирж оруулах, “Сонгох” дарах эсвэл “🔗 Линк”-ээр Google Drive / OneDrive линк оруулна. Линкийн эрх «Anyone with the link» байх ёстой.

            Хэрэглэгчид

            Хэрэглэгч бүр өөрийн нэр, нууц үгээр нэвтэрч, үйлдэл бүр нэрээр бүртгэгдэнэ (DOC-1917).
            Role-ийн эрх
            • ДАГ-ын захирал — бүх тайлан; санал шийдвэрлэх, «Батлаад илгээх», эцэслэн батлах, эцсийн тайлан татах
            • Ахлах аудитор, Аудитор — зөвхөн өөрийн болон багийн тайлан; хянуулах, засвар оруулах; захирал илгээсэн саналыг л харна
            • Admin — хэрэглэгч, эрх удирдах
            Шинэ хэрэглэгч
            Role: Гишүүн (анхдагч) — бүх review-г харах, үүсгэх, устгах, Docs бэлтгэх · Admin — дээрх + хүн нэмэх, хаах · Аудитор — зөвхөн өөрийн review · Удирдлага — зөвхөн харах, татах.
